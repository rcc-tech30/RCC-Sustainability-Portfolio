# RCC Holdings Emissions & Decarbonization

This project combines an Excel greenhouse gas calculator with a native Power BI emissions and decarbonization analysis. It demonstrates activity-data capture, emissions calculations, reduction planning, and decision-focused reporting for illustrative Australian and United Kingdom operations.

## Access the project

**[Download the Excel calculator](RCC_GHG_Calculator_AU_UK_2026.xlsx)**

Use the Project 01 request form on the [portfolio website](https://rcc-tech30.github.io/RCC-Sustainability-Portfolio/) to **Request the Power BI file**. A company email is required so requests can be reviewed before access is provided.

The Power BI file is not stored in this public repository. Microsoft Power BI Desktop is required to open an approved copy.

## What it demonstrates

- Scope 1, Scope 2, and selected Scope 3 calculation workflows
- Australian and United Kingdom emission-factor references
- Formula-driven data quality checks and reporting summaries
- User-defined decarbonization targets and reduction levers
- Waterfall analysis of projected emissions reductions
- Native Power BI modelling and executive reporting

## Important boundaries

The workbook uses illustrative sample data and is intended as a practical portfolio demonstration. It is not client work, external assurance, certification, regulatory advice, or a formal greenhouse gas inventory. The public sample does not apply market-based Scope 2 emission factors or contractual instruments.
