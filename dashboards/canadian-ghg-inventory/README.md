# Canadian GHG Inventory 2026

**[Download the Canadian GHG inventory workbook](Canadian_GHG_Inventory_2026_Scope1_Scope2.xlsx)**

A formula-driven Excel portfolio sample demonstrating Scope 1 and Scope 2 greenhouse-gas accounting using Canadian emission-factor references. The public download is a metadata-sanitized copy for portfolio distribution.

## What it demonstrates

- Dashboard summary for a 2026 reporting year
- Scope 1 mobile-combustion activity and Scope 2 purchased-electricity calculations
- Emission-factor and GWP reference tables
- Instructions and methodology notes inside the workbook
- Workbook-based traceability from activity data to reported emissions

The company, facilities, activity quantities, and figures are fictional and created for demonstration and portfolio purposes. The workbook is not client work, an official inventory, external assurance, certification, or regulatory advice. Microsoft 365 or Excel 2021+ is recommended because the workbook uses modern lookup and dynamic-array functions.
