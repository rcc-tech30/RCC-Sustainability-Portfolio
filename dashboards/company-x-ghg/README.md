# Company X GHG Dashboard

This folder contains an interactive greenhouse-gas dashboard created as a portfolio example.

## View the live dashboard

The easiest way to see the sample is to open:

**[Launch the Company X GHG Dashboard](https://rcc-tech30.github.io/RCC-Sustainability-Portfolio/dashboards/company-x-ghg/)**

The dashboard is designed as a 16:9 presentation canvas and is best viewed on a desktop or laptop.

## View it from a downloaded repository

1. Download or clone this GitHub repository.
2. Open this folder: `dashboards/company-x-ghg`.
3. Double-click `index.html` to open the dashboard in your web browser.

No installation, account, package, or build command is required.

## What the sample demonstrates

- Executive overview of reported emissions
- Scope 1, Scope 2, and Scope 3 analysis
- Market- and location-based Scope 2 presentation
- Data-quality and calculation-method indicators
- Net-zero target pathway communication
- Interactive filters, presentation controls, and an HTML download option
